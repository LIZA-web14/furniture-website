# 🛋 Интернет-магазин мебели

Адаптивный многосекционный лендинг интернет-магазина мебели, разработанный по макету из Figma.

🔗 **Демо онлайн:** [Открыть сайт магазина](https://liza-web14.github.io/furniture-website/)

---

### 🛠 Стек технологий:
- HTML5 (семантическая верстка)
- CSS3 / Flexbox / Grid
- Адаптивная и кроссбраузерная верстка под мобильные устройства и планшеты
- Подключение шрифтов (Google Fonts)

---

### ✨ Особенности проекта:
- Главный экран (Hero) с акцентным предложением.
- Каталог категорий и карточки товаров с ценами.
- Адаптивное меню и удобная навигация.
- Полная адаптивность под любые разрешения экранов (Mobile-first / Responsive).
